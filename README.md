# سولي العسولي — Soli Al-Asouli

متجر وهوية رقمية عربية RTL لمنتجات سولي العسولي: العطور، البخور، الريحة السودانية والمنتجات السودانية.

## الهوية البصرية

- عنابي عميق: `#5A1F2B`
- ذهبي معتّق: `#C49A5A`
- عاجي دافئ: `#F5EFE6`
- العناوين: IBM Plex Sans Arabic
- النصوص: Tajawal

## المزايا الحالية

- واجهة عربية RTL كاملة
- Hero بصري فاخر للعلامة
- أقسام: المنتجات، الريحة السودانية، طقوس سولي، الهدايا، القصة، المراجعات والمجتمع
- متجر بفلترة حسب الفئة
- إضافة للمفضلة
- سلة جانبية تفاعلية
- تعديل الكميات وحساب الإجمالي
- تصميم متجاوب للجوال والتابلت وسطح المكتب
- SEO metadata أساسية
- Next/Image و Next Font

## التشغيل محليًا

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

## البناء للإنتاج

```bash
npm run build
npm start
```

## المرحلة التالية المقترحة

ربط المتجر بقاعدة بيانات ونظام إدارة منتجات، إضافة صفحات تفاصيل المنتجات والدفع الحقيقي، وربط وسائل الدفع والشحن المناسبة للسوق المستهدف.
